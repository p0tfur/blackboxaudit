  • Bezpieczne zasoby (HTTPS):
    • Skrypt JavaScript (https://example.com/secure-script.js)
    • Arkusz stylów CSS (https://example.com/secure-style.css)
  • Niebezpieczne zasoby (HTTP):
    • Skrypt JavaScript (http://example.com/insecure-script.js)
    • Arkusz stylów CSS (http://example.com/insecure-style.css)
